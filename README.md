# JazzMusic-Recognition

This is a music recognition model.

Around 80 pieces of Jazz music are selected.

Each training and testing sample is a 20-second piece randomly selected from the 80 Jazz music pieces.

A CNN-based model is used for training.

The model combines the features of Mel-Spectrogram, MFCC, Chroma Features, Zero-Crossing Rate, Spectral Centroid, and Spectral Roll-off.

The model achieves a final accuracy of 96%.
