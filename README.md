# JazzMusic-Recognition
This is a music recognition model, with around 80 pieces of Jazz Musics are selected.
Each training and testing sample is a 20 second piece randomly selected from the 80 Jazz musics.
A CNN based model is used for training,
and the model combines the features of Mel-Spectrogram, MFCC, Chroma Features, Zero-Crossing rate, Spectral centroid, and Spectral Rollff
